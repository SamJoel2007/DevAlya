# DevAlya - AI Code Generator

**DevAlya** is a specialized desktop application built with Python that serves as an intelligent code generator for web development. Powered by the Claude 3 Opus model and ElevenLabs voice synthesis, Alya acts as a virtual pair programmer that generates, speaks, and saves production-ready code.

## 🚀 Features

* **AI Code Generation:** Generates complete, functional HTML, CSS, and JS code using Bootstrap.
* **Voice Feedback:** Integrated ElevenLabs API allows Alya to speak to you throughout the generation process.
* **Auto-Saving:** Automatically saves generated code to an `index.html` file for immediate testing.
* **Sleek GUI:** A clean, dark-themed interface built using Tkinter.
* **Simple Workflow:** Just type your request, and Alya handles the rest.

## 🛠️ Tech Stack

* **Language:** Python
* **GUI Framework:** Tkinter
* **AI Model:** Anthropic Claude (Claude 3 Opus)
* **Voice Synthesis:** ElevenLabs
* **Image Processing:** Pillow (PIL)

## 📋 Prerequisites

Before running the application, ensure you have Python installed and the following API keys:
1.  **Anthropic API Key:** To power the code generation.
2.  **ElevenLabs API Key:** To enable the voice synthesis.
